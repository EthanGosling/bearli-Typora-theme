# Bear - Typora Theme

复刻熊掌记（Bear 2）默认主题 Red Graphite 的 Typora 笔记样式。

## 安装

1. 下载 [`bear.css`](bear.css)
2. 打开 Typora，菜单 → Preferences → Appearance → Open Theme Folder
3. 把 `bear.css` 复制进去
4. 重启 Typora，在 Themes 菜单选择 **Bear**

## 特点

- 色值取自 Bear.app 内置 Red Graphite.theme
- 字号、行距、间距根据 Bear 2x 截图实测并换算为 CSS px
- 使用 Bear Sans UI 专有字体（从本机 Bear.app 加载，未装 Bear 时回落到 Avenir Next 和苹方）
- 表格、列表、待办、引用、代码块等元素样式均对齐 Bear 实际渲染效果
